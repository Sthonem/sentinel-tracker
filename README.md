# Sentinel Tracker PG

Real-time visualization of Sentinel-1 (SAR) and Sentinel-2 (MSI) satellite constellations using CesiumJS.

Project for the Geographic Information Systems course at Gdańsk University of Technology.

## Structure
- `frontend/` — Vite + React + Resium + Cesium
- `backend/` — Python FastAPI + TLE fetcher
